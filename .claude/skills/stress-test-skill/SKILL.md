# Full-Stack Stress Test Skill

Stress tests, validates hosting, asserts end-to-end communication, and enforces code coverage
for Angular + FastAPI + Docker + Nginx stacks. Fixes every failure in a loop until the
configured health score and coverage targets are met.

Every output is **written code** — test files, config patches, fix diffs, and scripts.
Nothing is left as prose advice or a "prompt to paste elsewhere."

---

## Core contract: output is always code

| Phase output | Format |
|---|---|
| Detection scan | Bash commands executed live; findings written to `stress-test-report/detection.md` |
| Hosting probes | Shell script `stress-test-report/probe_hosting.sh` — executed immediately |
| Communication matrix | Python script `stress-test-report/probe_comms.py` — executed immediately |
| Stress tests | k6 / pytest / shell scripts under `stress-test-report/tests/` — executed immediately |
| Missing test files | Full `.py` / `.spec.ts` / `.e2e.ts` files written into the project tree |
| Config fixes | Actual edits to `nginx.conf`, `docker-compose.yml`, `main.py`, etc. via Edit/Write |
| Coverage gaps | Complete test files written — no stubs, no TODOs |
| Final report | `stress-test-report/REPORT.md` written to disk |
| Re-run script | `stress-test-report/run_all.sh` — handoff artifact for the user |

All generated scripts go under `stress-test-report/` at the project root (create if missing).
All fix files are written **in-place** inside the project tree at their correct paths.

---

## Default targets

| Target | Default | Override syntax |
|--------|---------|----------------|
| Overall health score | 98% | *"use 95% health target"* |
| Code coverage (line + branch) | 100% | *"use 90% coverage"* |
| Max fix iterations | 15 | *"max 5 iterations"* |
| Hosting probe pass rate | 100% | Not configurable — always mandatory |

## Phase 0 — Auto-detect (run first, always)

Execute these commands live with Bash. Write findings to `stress-test-report/detection.md`.

```bash
# Services
cat docker-compose*.yml 2>/dev/null
grep -E "^\s{2}[a-zA-Z]" docker-compose*.yml 2>/dev/null | tr -d ':' | awk '{print $1}'

# Nginx
find . -name "nginx.conf" -o -name "default.conf" | xargs grep -l "location" 2>/dev/null
cat nginx/*.conf nginx.conf default.conf 2>/dev/null

# FastAPI structure
grep -rn "APIRouter\|include_router\|@app\." --include="*.py" . | head -40
grep -rn "lifespan\|startup\|shutdown" --include="*.py" . | head -20

# Angular
find . -name "environment*.ts" ! -path "*/node_modules/*"
grep -rn "loadChildren\|loadComponent\|HttpClient" --include="*.ts" . \
  ! -path "*/node_modules/*" | head -30

# Existing tests
find . \( -name "test_*.py" -o -name "*_test.py" \) ! -path "*/node_modules/*"
find . \( -name "*.spec.ts" -o -name "*.e2e.ts" \) ! -path "*/node_modules/*"
find . -name "playwright.config.*" -o -name "cypress.config.*" 2>/dev/null

# Auto-detect extras (Celery, MinIO, Traefik, etc.)
grep -Ei "celery|minio|traefik|rabbitmq|kafka|keycloak" docker-compose*.yml 2>/dev/null
```

Record per component: name, type, file path, exposed ports, risk (HIGH/MEDIUM/LOW),
estimated existing test coverage. Auto-add any extra detected services to scope.

## Phase 1 — Hosting verification

Write `stress-test-report/probe_hosting.sh`, then execute it with Bash.
If the exit code is non-zero, fix the root cause by editing the relevant file before Phase 2.

```bash
#!/usr/bin/env bash
# probe_hosting.sh — generated by stress-test-fullstack skill
set -euo pipefail
PASS=0; FAIL=0

probe() {
  local name="$1" cmd="$2" expect="$3"
  result=$(eval "$cmd" 2>&1) || true
  if echo "$result" | grep -q "$expect"; then
    echo "PASS  $name"; ((PASS++))
  else
    echo "FAIL  $name  =>  ${result:0:120}"; ((FAIL++))
  fi
}

probe "Angular root 200"    "curl -sI http://localhost/ | head -1"                    "200"
probe "Angular deep link"   "curl -sI http://localhost/app/deep/route | head -1"     "200"
probe "Gzip enabled"        "curl -sI --compressed http://localhost/"                "gzip"
probe "FastAPI internal"    "docker exec \$(docker ps --filter name=api -q | head -1) curl -s http://localhost:8000/health" '"status"'
probe "FastAPI via Nginx"   "curl -s http://localhost/api/health"                    '"status"'
probe "No 502 on /api"      "curl -sI http://localhost/api/health | head -1"         "200"
probe "SSE route reachable" "curl -sN --max-time 3 http://localhost/api/stream 2>&1 || true" "data:"
probe "Env vars loaded"     "docker exec \$(docker ps --filter name=api -q | head -1) env | grep -c 'DATABASE_URL\|REDIS_URL'" "[1-9]"

echo ""; echo "Hosting: $PASS passed / $((PASS+FAIL)) total"
[ "$FAIL" -eq 0 ] || { echo "HOSTING BLOCKED — fix P0 failures before Phase 2"; exit 1; }
```

Read `references/hosting-probes.md` for the fix template for each failure type.
Write the fix directly into the relevant file (nginx.conf, docker-compose.yml, etc.),
then re-execute the script to confirm the probe now passes.

## Phase 2 — Communication matrix

Write `stress-test-report/probe_comms.py`, then execute it with Bash.
Fix every broken link before computing any health score.

```python
#!/usr/bin/env python3
"""probe_comms.py — generated by stress-test-fullstack skill"""
import subprocess, httpx, asyncio, sys

results = []

def record(link, ok, detail=""):
    status = "OK" if ok else "FAIL"
    icon   = "OK  " if ok else "FAIL"
    results.append({"link": link, "ok": ok, "detail": detail})
    print(f"{icon}  {link}  {detail[:80]}")

async def run():
    async with httpx.AsyncClient(base_url="http://localhost", timeout=10) as c:
        r = await c.get("/")
        record("Browser→Nginx /", r.status_code == 200, str(r.status_code))

        r = await c.get("/app/deep/route")
        record("Angular deep link", r.status_code == 200, str(r.status_code))

        r = await c.get("/api/health")
        record("Nginx→FastAPI proxy", "status" in r.text, r.text[:60])

        r = await c.post("/api/v1/agent/query", json={"prompt": "ping"})
        record("Angular→FastAPI REST", r.status_code in (200, 422), str(r.status_code))

    def exec_in_api(cmd):
        api_id = subprocess.check_output(
            "docker ps --filter name=api -q", shell=True
        ).decode().strip().split()[0]
        return subprocess.run(
            ["docker", "exec", api_id, "python", "-c", cmd],
            capture_output=True, text=True, timeout=10
        )

    res = exec_in_api(
        "import asyncio,asyncpg,os; asyncio.run(asyncpg.connect(os.environ['DATABASE_URL']))"
    )
    record("FastAPI→PostgreSQL", res.returncode == 0, res.stderr[:80])

    res = exec_in_api(
        "import asyncio,redis.asyncio as r,os; asyncio.run(r.from_url(os.environ['REDIS_URL']).ping())"
    )
    record("FastAPI→Redis", res.returncode == 0, res.stderr[:80])

    broken = [r for r in results if not r["ok"]]
    print(f"\nComms: {len(results)-len(broken)}/{len(results)} links OK")
    if broken:
        print("P0 broken links:")
        for b in broken:
            print(f"  FAIL  {b['link']}: {b['detail']}")
        sys.exit(1)

asyncio.run(run())
```

Read `references/communication-matrix.md` for the fix template for each broken link type.
Write the fix to the relevant file, re-run only the affected probe.

## Phase 3 — Stress test suite

Write each script to `stress-test-report/tests/` and execute immediately.

| Script | Tool | Threshold |
|--------|------|-----------|
| `tests/load_test.js` | k6 | p95 < 2s, error rate < 1% |
| `tests/memory_leak.py` | pytest + tracemalloc | heap growth < 50MB over 200 calls |
| `tests/test_llm_timeout.py` | pytest-asyncio | 504 returned on 30s+ delay, no hang |
| `tests/test_cors_auth.sh` | curl | CORS headers present, 401 on expired JWT |
| `tests/test_sse_chain.py` | httpx async | events flow, clean closure |
| `tests/test_nginx_buffer.sh` | curl | chunked transfer, no truncation |
| `tests/test_docker_hc.sh` | docker + curl | healthy after restart, depends_on respected |
| `tests/test_env_config.py` | pytest | ValidationError on missing vars |

`app/routers/debug.py` (guarded by `settings.DEBUG`) and register it in `main.py`.

## Phase 4 — Test coverage enforcement

### FastAPI
```bash
pytest --cov=app --cov-report=term-missing --cov-branch --cov-fail-under=98
```
For every module below 98%: read the source, identify uncovered lines/branches,
write missing tests into the existing `tests/test_<module>.py` (or create it).
Every test must make real assertions — no `assert True`, no empty test bodies.

### Angular
```bash
ng test --no-watch --code-coverage --browsers=ChromeHeadless
```
For every file below 98%: write missing specs into the existing `.spec.ts`.
Priority: interceptors → guards → services → smart components → pipes.

### E2E
Write Playwright tests to `e2e/` for every required flow missing a test:
login, logout, agent query + stream render, error state, deep link, token expiry.
```bash
npx playwright test --reporter=html
```

### Contract
```bash
curl -s http://localhost/api/openapi.json > stress-test-report/openapi-actual.json
```
Write `stress-test-report/contract_check.py` that asserts every Angular `HttpClient`
path exists in the OpenAPI schema. Execute it. Fix any drift found.

Read `references/coverage-rules.md` for per-module targets and test generation patterns.

## Phase 5 — Fix loop

```
health_score = (hosting × 0.30) + (comms × 0.30) + (stress × 0.25) + (coverage × 0.15)
```

While `health_score < 98% AND iterations_remaining > 0`:
1. Execute `probe_hosting.sh` + `probe_comms.py` for current state
2. Rank: P0 (hosting/comms broken) → P1 (stress FAIL) → P2 (coverage gap) → P3 (WARN)
3. Write the fix as an actual file edit or new file — use Edit/Write/Bash, not prose
4. Re-run only the affected script
5. Recompute health_score and iterate

**Non-negotiable:**
- Every fix is a real file write — not a code block in a markdown comment
- No suppressing errors, disabling healthchecks, or inflating score without real fixes
- SKIP (not PASS) if a required tool (`k6`, `playwright`, etc.) is not installed — record in `REPORT.md`

## Phase 6 — Final report

Write `stress-test-report/REPORT.md` (use template in `references/report-template.md`).

Write `stress-test-report/run_all.sh`:

```bash
#!/usr/bin/env bash
# run_all.sh — re-run the complete suite at any time
set -euo pipefail
echo "=== Hosting ===" && bash stress-test-report/probe_hosting.sh
echo "=== Comms ===" && python3 stress-test-report/probe_comms.py
echo "=== Stress ===" && k6 run stress-test-report/tests/load_test.js
pytest stress-test-report/tests/ -v
echo "=== Coverage ===" && pytest --cov=app --cov-report=term-missing --cov-branch --cov-fail-under=98
ng test --no-watch --code-coverage --browsers=ChromeHeadless
npx playwright test
echo "=== Contract ===" && python3 stress-test-report/contract_check.py
echo "=== All done ==="
```
